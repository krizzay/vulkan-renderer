# vulkan renderer

A small (and very work in progress) vulkan renderer with a variety of features.
Currently being heavily reformated.

### features
+ blinn phong shading
+ compute shaders
+ mip maps
+ multi sampling
+ camera controls
+ imgui UI

### controls
+ mouse to look around
+ wasd to move around
+ space & left shift for up and down
+ r to reset position to origin
+ q to free cursor
+ esc to close window

### this project requires
+ vulkan
+ vulkan validation layers
+ glfw3
+ glm
+ glslc

You can build the project with cmake.
